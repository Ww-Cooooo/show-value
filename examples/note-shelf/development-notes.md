# 虚构开发记录

这些是为例子编写的输入背景，不是真实用户访谈或历史聊天摘录。

1. 最初需求：作者平时把文章摘录记在 JSON 中。准备写一篇内容时，希望只拿出相关标签的摘录，整理为能继续编辑的文字。
2. 第一版想法：每条摘录只导出正文，最后统一附一张来源清单。
3. 虚构作者的确认：改成每条摘录旁边就带标题和来源链接。写作时需要回看原文，分开的清单不方便对应。这项决定已经体现在 shelf.py 中。
4. 曾讨论：直接抓取网页、导出 PDF。两项都没有做；当前没有发布版本，也没有真实用户反馈、提效数字或完整系统兼容性测试。
5. 使用范围：当前 CLI 读取用户准备的本地 JSON，输出 Markdown 文本。资料条目与链接由用户提供；来源网址只是测试地址，不应联网访问。
